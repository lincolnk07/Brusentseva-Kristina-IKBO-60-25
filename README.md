# Визуализатор графа зависимостей NuGet

Проект реализуется по пяти этапам практической работы. Параметры запуска
задаются в `config.toml`; конфигурация содержит шесть полей.

## Этап 1. Конфигурация

```sh
./run.sh config.toml 1
```

## Этап 2. Получение прямых зависимостей NuGet

```sh
./run.sh config.toml 2
```

## Этап 3. Рекурсивный DFS

```sh
./run.sh config_test.toml 3
```

## Этап 4. Порядок загрузки

Зависимости перечисляются перед пакетами, которые от них зависят. При цикле
линейный порядок загрузки не выводится:

```sh
./run.sh config_test.toml 4
```
